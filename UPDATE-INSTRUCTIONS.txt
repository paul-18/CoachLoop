COACH LOOP v79 GITHUB UPDATE

This ZIP is an update package for paul-18/CoachLoop at commit
97a10f4c26660854f4674ba36cce4ad2e6be06b0 (the onboarding update).
It replaces matching source files and adds new ones in the existing app.
It has no extra enclosing folder and does not create another app.

1. In the live app, download a full JSON backup and save it somewhere private.
   Do not upload that backup to the public GitHub repository.
2. Upload CoachLoop-v79-GitHub-Update.zip to the repository's main folder
   (the folder containing package.json and README.md), and commit the upload.
3. Open the existing Codespace terminal in /workspaces/CoachLoop.
4. Run each command below separately. Wait for it to finish.

   git status --short

   If this lists changed files, preserve that work before continuing.
   If it prints nothing:

   git pull --ff-only
   unzip -o CoachLoop-v79-GitHub-Update.zip
   npx --yes pnpm@11.25.0 install --frozen-lockfile
   npx --yes pnpm@11.25.0 exec tsc --noEmit
   npx --yes pnpm@11.25.0 run lint
   npx --yes pnpm@11.25.0 run test
   npx --yes pnpm@11.25.0 run build
   node scripts/check-pwa.mjs

5. Only after every check succeeds, run these separately:

   rm CoachLoop-v79-GitHub-Update.zip
   git add app tests scripts .github/workflows/pages.yml package.json eslint.config.mjs README.md UPDATE-INSTRUCTIONS.txt V79-UPDATE-NOTES.md CoachLoop-v79-GitHub-Update.zip
   git diff --cached --stat
   git commit -m "Port Coach Loop v79 and add customizable coverage and quick log"
   git push

6. In GitHub, open Actions and check the newest Publish Coach Loop PWA run.
   It now checks types, lint, tests, the build, and offline assets before deploying.
7. Open the live app online. Finish any workout and wait for local saving.
   Close all Coach Loop Safari/PWA windows, then reopen. Settings shows v79.
8. Settings -> Appearance & quick log:
   - Select the male or corrected female strength-coverage visual.
   - Show/hide quick-log activities, including Water polo.
   - Use the arrows to change their order. Restore default shortcuts resets them.
   Profile/goals editing uses Save/Cancel. Ranked goals remain visible in Coach.

The same live URL is used. GitHub Pages stays local-only, with no Sites database
or automatic cross-device sync. Your existing on-device log should remain;
keep its backup. Do not clear Safari storage to refresh the app.

Large-chunk warnings are non-blocking if the command completes successfully.
If any command fails, stop before committing and share its error output.
