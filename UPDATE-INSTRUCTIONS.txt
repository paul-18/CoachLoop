COACH LOOP v83 — README AND REPOSITORY CLEANUP

Apply this AFTER your v83 app update. It stays v83: this is housekeeping, not a
new feature release. Use this ZIP only; do not reapply the earlier v83 ZIP.
The new build identifier lets installed apps receive the smaller stylesheet.

1. GitHub → paul-18/CoachLoop → Code → main → Add file → Upload files.
   Upload CoachLoop-v83-Repo-Cleanup.zip beside package.json. Commit the upload.
2. Open your existing Codespace terminal in /workspaces/CoachLoop.
   Run each command individually, waiting for completion. Stop on a failure.

   git status --short

   If it lists local changes, preserve them before continuing. If empty:

   git pull --ff-only
   unzip -o CoachLoop-v83-Repo-Cleanup.zip
   node scripts/cleanup-repo.mjs

   This last command previews the exact 64 files; it does not delete yet.
   See REPOSITORY-CLEANUP.md for why they are unused and what is kept.
   Now apply those reviewed deletions:

   node scripts/cleanup-repo.mjs --apply

   If it reports a changed file, stop. It will not delete your modified files.
   Do not use a force-delete command to bypass this safeguard.

3. Run the checks, separately:

   npx --yes pnpm@11.25.0 install --frozen-lockfile
   npx --yes pnpm@11.25.0 exec tsc --noEmit
   npx --yes pnpm@11.25.0 run lint
   npx --yes pnpm@11.25.0 run test
   npx --yes pnpm@11.25.0 run build
   node scripts/check-pwa.mjs

4. Only after all checks pass:

   git rm CoachLoop-v83-Repo-Cleanup.zip
   git add README.md UPDATE-INSTRUCTIONS.txt REPOSITORY-CLEANUP.md scripts/cleanup-repo.mjs
   git --no-pager diff --cached --stat
   git commit -m "Refresh user README and remove unused Coach Loop templates"
   git push

   The cleanup script already staged the 64 deletions. The git add command stages
   all four files supplied in this ZIP. Review the list before committing.
   No personal backup, dist or node_modules should appear.
5. GitHub → Actions → newest Publish Coach Loop PWA run: wait for green success.
6. In your installed app, finish/save any workout. Settings → Check updates →
   Restart to update when available. Release still says v83; the build changes.
   Check Today, Coach, Progress and Settings, then the workout header/rest timer.

The deletions are recorded in Git history and can be recovered. Browser log data
is not stored in these repository files. This package does not remove workouts,
goals or backups from your phone. Do not clear website data to update.
