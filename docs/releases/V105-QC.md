# Coach Loop v105 candidate QC

## Automated release gate

- Run `pnpm install --frozen-lockfile` and `pnpm release:check`.
- Confirm the React DOM regression exercises cancel/retry, candidate completion, note and session effort persistence, and the 10 km / 19 min warning path.
- Confirm the unfinished activity list and count stay aligned for skipped and incomplete activities.
- GitHub Actions must pass and the Pages deployment must complete before v105 is described as published.

## Device checks

- On iPhone, update to v105 and verify existing history, notes, profile, goals and measurements remain.
- Reproduce the second finish review: mark typed actuals complete, enter session effort 7 and a note, save, then open History/Edit and verify both remain. Repeat and choose Keep training; confirm the activity remains incomplete and the data is unchanged.
- Enter a genuinely unusual result (for example 10 km in 19 min) and verify the warning and explicit “Save unusual entry” final action.
- Check the bottom navigation, keyboard clearance, narrow phone wrapping, and mobility movement names at phone width. Automated WebKit viewport checks do not certify Safari, Home Screen PWA, share sheet, VoiceOver or physical-device layout.
