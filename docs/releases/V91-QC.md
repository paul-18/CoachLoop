# v91 iPhone QC

Save and verify a private JSON backup in Files first. Record v91, build ID, iOS version, Home Screen vs Safari and orientation. Never use a personal log for destructive or near-limit stress tests.

1. Online, finish/close editors and wait for Saved. Settings -> Check updates -> Restart to update. Confirm v91 and retained workouts/profile/goals. Another open window must be respected; there is no automatic mid-workout reload.
2. After Offline files says Ready, use airplane mode: launch, log actual reps/load, wait for Saved, finish, reopen and inspect History. Return online afterward.
3. Open/close profile, note, backup verification and import dialogs, then use all tabs. Check fixed bottom navigation and Dynamic Island clearance in portrait/landscape with the keyboard open/closed. No safe-area CSS was changed.
4. Paste CARDIO|Run/walk intervals with DURATION but no TYPE: preview must warn about inferred walk. Add TYPE|run: no inferred warning and run is selected. Nothing counts as performed until logged/completed.
5. Confirm Settings still has eight themes, quick-log ordering, Last 7 days choices and Progress options. The male/female illustration does not change totals. Open ranked Coach goals.
6. Save to Files, Verify saved backup, and cancel selection/close verification; the current log must stay unchanged. In a disposable profile, test merge/complete restore and reopen.
7. Normal updates should not reach the unavailable-files page. If it occurs, note the build/network state, go online and tap Try again. Do not clear site data or uninstall. Automated probes simulate evicted/mismatched files; don't manually damage your personal installation's cache to test this.
8. Save-failure tests belong in the isolated automated harness/disposable log: failed Finish must retain editor and unfinished state; Retry saves editable state, not a previously rejected Finish. Genuine Not saved errors require attention and an external backup before closing.
9. In Settings, requested/pending update notices should remain readable. Late save failure defers restart. Physical delayed-worker/background timing remains device-specific.
10. For an unusually large backup, measure opening/verification/restore only in a disposable profile. The 50 MB limit is unchanged; main-thread costs are not certified on iPhone. CSV control-character handling should also be checked in the actual spreadsheet program before treating it as universally safe.

Existing v90 large-history, VoiceOver, enlarged-text and durable-save checks remain applicable. Node/DOM checks do not certify Safari eviction, physical safe areas or Files completion.
