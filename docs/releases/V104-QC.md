# Coach Loop v104 candidate QC

## Automated release gate

- Run `pnpm install --frozen-lockfile`.
- Install WebKit with `pnpm exec playwright install --with-deps webkit` in CI, or `pnpm exec playwright install webkit` locally.
- Run `pnpm release:check`. It must pass TypeScript, lint, tests, production build, PWA generation/behavior and the WebKit mobile navigation smoke.
- Confirm the PWA and Flutter `training_rules_v1.json` fixture files are byte-for-byte identical.
- Confirm FITLOG fixture coverage retains malformed reps, a flattened block, duplicate blocks and surrounding explanation outside one valid FITLOG block.

## Physical iPhone checks still required

- Confirm v104 appears in Settings after update and existing log, profile, goals and measurements remain.
- Exercise an implausible distance/time entry in a repeated-effort activity while its effort is still unchecked. Confirm warning text appears before the finish confirmation and **Save unusual entry** is the explicit final action.
- Enter actual results but leave an activity incomplete. Try each finish choice; the second finish review must match the chosen candidate and retain the entered numbers.
- Switch all five tabs repeatedly, check bottom navigation and content clearance with the keyboard, and check the app in Safari and Home Screen mode.
- Use Files/share-sheet to save and verify a backup. WebKit viewport checks do not validate native file sharing, VoiceOver, standalone PWA behavior, or iOS storage policy.
