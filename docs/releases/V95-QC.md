# v95 iPhone check

1. Settings shows v95 after Restart to update.
2. Settings → Notifications shows "Not available" or "Off" before enabling (wording depends on install state).
3. Install the app to the Home Screen (iOS 16.4+), reopen, tap Enable notifications, allow the system prompt. Status reads On.
4. Start a workout, complete a set with a rest timer, switch to another app before the timer ends. A silent "Rest over" notification appears. Tap it: Coach Loop comes to the front.
5. While the app is visible when the timer ends: no system notification (the on-screen timer covers it), no duplicate.
6. Turn notifications off in Settings: no notification on the next rest.
7. Deny the system prompt: Settings explains how to re-allow in iOS Settings; "Check again" picks up the change.
8. Existing log, backups, and recovery copies are unaffected (no storage change).
